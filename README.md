# Aurore Pro

## Utilisation :

1. cloner de dépot :
```Bash
git clone https://github.com/Scratch-OS-X/Aurore-Pro.git
```
2. Aller dans le dossier :
```Bash
cd Aurore-Pro
```

3. Lancer le programme :

   **MacOS / Linux :**
   ```bash
   python3 script.py
   ```

   **Windows :**
   ```bash
   python script.py
   ```

### Mise à jour :
```Bash
cd Aurore-Pro
&&
git pull origin main
```
