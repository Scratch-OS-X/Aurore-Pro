# Aurore Pro

## Utilisation :

1. cloner de dépot :
```Bash
git clone https://github.com/Scratch-OS-X/Aurore-Pro.git
```
2. Aller dans le dossier :
```Bash
cd Aurore-Pro
```

3. Lancer le programme :

   **MacOS / Linux :**
   ```bash
   python3 script.py
   ```

   **Windows :**
   ```bash
   python script.py
   ```

## TOTAL (toutes les commandes) :

**MacOS / Linux :**
```bash
git clone https://github.com/Scratch-OS-X/Aurore-Pro.git
cd Aurore-Pro
python3 script.py
```

**Windows :**
```bash
git clone https://github.com/Scratch-OS-X/Aurore-Pro.git
cd Aurore-Pro
python script.py
```
